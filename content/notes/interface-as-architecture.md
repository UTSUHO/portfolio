# 01 / 结构先于样式

Interfaces are often treated as decoration applied after the structure is finished. A better analogy is architecture: the interface is the load-bearing surface through which users understand and operate the system.

Good interface design begins with the underlying structure. What are the entities? What are their relationships? What actions are possible? Only after answering these questions does visual form become meaningful.

---

# 02 / 工业界面

Industrial control panels are a useful reference. They are dense, hierarchical, and unapologetically functional. Every element exists because an operator needs it.

- Borders define zones
- Labels identify functions
- Color indicates state
- Repetition creates rhythm

> An interface should feel like a room you can walk through, not a poster you read.

---

# 03 / 隐喻的应用

For this portfolio, the design system borrows from control panels:

- Fixed status bars provide global context
- A 12-column grid creates predictable spatial relationships
- Panels and dividers replace cards and shadows
- Motion is limited to state changes and reveals

---

# 04 / 结语

When interface and architecture are aligned, the result feels inevitable. Every decision has a reason, and every element has a place.
