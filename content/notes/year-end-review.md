# 01 / 做过的事

This year shipped more long-form work than I expected: a portfolio rebuild, several internal platform deliveries, and the first stable version of the AI training-inference dashboard. Each project reinforced the same habit: write down the interface contract before writing the component.

---

# 02 / 没做完的事

Some experiments stayed experiments. The mesh network prototype reached a clean checkpoint but was archived before production. The board game entered revision but not art direction. These are not failures; they are proof that the filtering process is working.

---

# 03 / 想开始的事

Next year I want to:

- Keep a tighter loop between reading and building.
- Publish shorter technical notes more often.
- Reduce the number of active side projects by half.
- Spend more time with systems that are slow by design: turn-based games, long essays, printed objects.

---

# 04 / 结语

The best planning tool is not a calendar. It is a clear statement of what you are willing to not do.
