# Line Sequence Agent Markdown Guide

This folder contains modular Markdown instructions for an agent implementing a Next.js-compatible Three.js line sequence animation system.

Start with:

```txt
00_MASTER_AGENT_PROMPT.md
```

Then follow the numbered files in order.

The intended data file is:

```txt
/line_sequence_classified.json
```

The animation should autoplay after loading. Scroll is not required for playback.
