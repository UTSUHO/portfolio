# Goal

展示一个项目。

页面重点不是展示代码。

而是展示：

这是一个完整的软件工程。

页面应该具有：

> 建筑方案展示

而不是

> Github README

左右双栏。

```
---------------------------------------------------

Header

---------------------------------------------------

---------------------------------------------------

---------------------------------------------------

Architecture         Metrics

---------------------------------------------------

Timeline             Tech Stack

---------------------------------------------------

---------------------------------------------------
```

左：

40%

右：

60%
